# portfolio-support-copilot

A customer-support copilot for an online store that sells physical movie media (Blu-ray, DVD, 4K UHD, box sets). One LangGraph run reads a support message, extracts structured fields, routes it, answers from help docs (RAG) or the business database (SQL), and pauses for human approval before risky actions like refunds.

See [SCOPE.md](SCOPE.md) for the full project scope. Implementation in progress.
